# dotnet-mcp-server

The pro-code MCP server in C# (ASP.NET Core, MCP C# SDK), hosted on Azure Container Apps.

- `src/Contoso.OrdersMcp/`: the server
- `tests/Contoso.OrdersMcp.Tests/`: unit tests
- `infra/`: deployment and health probes
- `test/`: curl, MCP Inspector and `.http` tests
