# Platform limits

<!-- cspell:ignore Substack -->

Character counts, hashtag limits and how much text shows before truncation. Platforms change these; when a
post is close to a limit, check the platform's current help page.

## LinkedIn

| Element | Limit |
| --- | --- |
| Max post characters | 3,000 |
| Visible before "…see more" | ~210 characters |
| Max comment characters | 1,250 |
| Hashtags | No official limit; use 3–5, at the end |
| Document (carousel) upload | PDF, PPT/PPTX or DOC/DOCX; keep under ~20 slides for completion |

## LinkedIn articles and newsletter editions

| Element | Limit |
| --- | --- |
| SEO title | Cut off after 60 characters in search results (LinkedIn Help) |
| SEO description | Aim for 140–160 characters (LinkedIn Help) |
| Cover image | 1920 × 1080 recommended (LinkedIn Help); other sizes circulate, but this is LinkedIn's own figure |

## X (Twitter)

| Element | Limit |
| --- | --- |
| Max post characters | 280 (standard) / 25,000 (Premium) |
| Visible in feed | Full post up to 280; longer posts truncate |
| Hashtags | No official limit; use 0–2 |
| Video | Up to 2:20 standard; aim for 8 s+ to earn video credit |

## Bluesky

| Element | Limit |
| --- | --- |
| Max post length | 300 characters (graphemes) |
| Images | Up to 4 per post |
| Links | Rendered as a link card; the URL counts toward the limit only if left in the text |
| Hashtags | Supported; use 0–2 |

## Reddit

| Element | Limit |
| --- | --- |
| Post title | 300 characters |
| Post body / comment | 40,000 / 10,000 characters |
| Self-promotion | Set per subreddit — read the rules |

## Hacker News

| Element | Limit |
| --- | --- |
| Title | 80 characters |
| Text posts | URL **or** text; Show HN can include text explaining what it is |

## YouTube Shorts

| Element | Limit |
| --- | --- |
| Length | Up to 3 minutes; 30–60 s works best for demos |
| Title | 100 characters (~70 visible) |
| Description | 5,000 characters |
| Hashtags | 1–5 for Shorts; more than 15 makes YouTube ignore all of them |

## TikTok

| Element | Limit |
| --- | --- |
| Caption | 4,000 characters; ~150 visible before "more" |
| Hashtags | Up to 5; use 3–5 |

## Instagram Reels

| Element | Limit |
| --- | --- |
| Caption | 2,200 characters; ~125 visible before "more" |
| Hashtags | Up to 5; use 3–5 |

## Facebook

Not a focus channel; Meta doesn't publish these, so the figures are third-party and approximate.

| Element | Limit |
| --- | --- |
| Post | 63,206 characters |
| Visible before "See more" | About 477 characters on desktop, fewer on mobile |
| Link or landscape image | 1200 × 630 |

## Substack

| Element | Limit |
| --- | --- |
| Post title | No published limit; it's the email subject, so keep it under ~60 characters |
| SEO title / description | Under 60 characters / 150–160 characters (Substack's SEO guide; defaults to title and subtitle) |
| Note length | No limit in Substack's help; Buffer documents 10,000 characters |
| Images per Note | Up to 6 images or GIFs (Substack Notes FAQ) |

## Usage tips

- Hashtags count toward character limits everywhere.
- Put the point before the truncation line; the rest is for readers who already care.
- On LinkedIn, put the blog link in the first comment; on Bluesky and Reddit, links are normal.
