# logic-apps

Logic Apps Standard workflows exposed as an MCP server.

- `src/`: the workflows `find_orders`, `get_order_status` and `create_return`, `host.json`, `parameters.json`
- `infra/`: the logic app and its Workflow Service Plan
- `test/`: MCP Inspector, curl and `.http` tests
- `.vscode/`: `mcp.json` for testing from VS Code
