# order-api

The Contoso Order Management API: the backend REST API that the MCP servers call, with in-memory demo data.

- `src/`: the API (three operations and the internal identity lookup)
- `data/`: the demo data set shared by every path
- `openapi/`: the full OpenAPI 3.0 description
